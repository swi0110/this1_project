# 프로토타입 디자인 보관본

메르헨 단위계 변환기의 **첫 프로토타입 디자인**입니다.
`index.html`을 더블클릭하면 그대로 실행됩니다.

- 보관일: 2026-09-12
- 시점: DESIGN.md v1.3 (미터 → 메따 기본, 소수점 2자리)
- 성격: 기능 검증용 중립 디자인 (연보라 계열, 시스템 산세리프)

## 왜 별도로 두는가

정규 버전 디자인은 [The Holy Maerchen Empire](https://www.theholymaerchenempire.com/)의
제국 문장(紋章) 스타일 — 진홍 바탕에 금색 세리프 — 을 따릅니다.
이 폴더는 그 이전의 중립적인 디자인을 비교·복원용으로 남겨둔 것입니다.

## 주의

**자기 완결형 스냅샷입니다.** `js/`와 `css/`를 자체 사본으로 갖고 있어
상위 폴더의 코드가 바뀌어도 영향을 받지 않습니다.
바꿔 말해 상위 폴더의 기능 수정이 여기에는 반영되지 않습니다.
기능을 손볼 곳은 항상 상위 폴더이고, 이 폴더는 건드리지 않습니다.
